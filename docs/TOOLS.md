# 能力地图

TripSight 通过 MCP 提供 **92** 个工具。大模型只理解你的话并调用它们；排程、检查、路线、版本和撤销都由这些确定性的工具完成。
本页由 `scripts/gen_tools_doc.py` 从 `tripcore/tools_catalog.py` 生成，请不要手改。

**标记**：只读 = 不改任何数据；生成文件 = 不改行程；会改行程/数据 = 助手只在你确认后才做，多数可 `undo`。

## 行程基础（10）

| 工具 | 性质 | 做什么 | 可以这样说 |
|---|---|---|---|
| `new_trip` | 会改行程/数据 | 新建一个行程并切换过去，旧行程保留。 | “帮我新建一个东京5日游” |
| `set_dates` | 会改行程/数据 | 设置或清除出行日期，营业时间和天气检查依赖它。 | “日期定在 10 月 12 日到 16 日” |
| `set_travelers` | 会改行程/数据 | 设置出行人数，门票和餐饮按人数估算。 | “一共 3 个人去” |
| `list_trips` | 只读 | 列出所有行程。 | “我有哪些行程” |
| `switch_trip` | 会改行程/数据 | 切换到另一个行程。 | “切换到杭州那个行程” |
| `rename_trip` | 会改行程/数据 | 改当前行程的名字（计划、恢复都行，可撤销，内容不动）。 | “这个行程名字起错了，改成“台州三日”” |
| `archive_trip` | 会改行程/数据 | 把行程归档（不删除文件，可手动移回）。 | “把去年的行程归档” |
| `open_workbench` | 只读 | 打开 TripSight 页面（拖动调整、预览手册、直接改图片和文字）。 | “打开 TripSight 看看” |
| `show_trip` | 只读 | 查看当前行程：每天的景点、交通、未安排项、粗略费用。 | “看看现在的行程” |
| `undo` | 会改行程/数据 | 撤销最近一次修改，可连续撤销。 | “撤销刚才的修改” |

## 承诺

- 不会替你订票、订酒店或付款。
- 所有改动先成为提案，你确认后才生效，随时可以撤销。
- 坐标、营业时间、路线、天气只来自地图服务和你；查不到就写“待核实”。
- 你的 key 只放在你自己的配置里，不会出现在页面或分享文件里。
- 分享时酒店、花费、照片默认不公开，由你决定。
